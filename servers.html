How to join

Follow these simple steps to join REALENVY in Minecraft.

  1. Open Minecraft

    Launch Minecraft Java Edition or Bedrock Edition.

  2. Add a server

    Go to Multiplayer on Java or Servers on Bedrock, then choose Add Server.

  3. Enter the address

    Copy the address of your chosen server. Bedrock players should also enter port 19132.

  4. Join and say hi

    Connect to the server and tell everyone you're from REALENVY!
